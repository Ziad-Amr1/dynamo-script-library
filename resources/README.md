# Resources

Shared, non-code assets used by tools and documentation.

## Belongs here

- Small icons or images referenced by tool READMEs.
- Synthetic sample data (CSV, JSON, Excel) used in examples.
- Reference tables and lookup data that are safe to redistribute.
- Screenshots or diagrams owned by the project.

## Rules

- No confidential project data, client names, addresses, or real Revit models.
- No unused binaries. If a tool does not reference an asset, do not commit it.
- Record the source and license of anything you did not create.
- Use descriptive kebab-case names, for example `sheet-numbering-example.csv`.
- Keep files small; optimize images and avoid duplicate copies.
- Prefer relative links from the tool README to the resource.

Shared assets are covered by the repository [MIT License](../LICENSE) only when
the project owns them. Third-party assets keep their own license.
