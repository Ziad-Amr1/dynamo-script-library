# Families

Tools that load, audit, place, document, or manage Revit families.

## Belongs here

- Family loading and reloading.
- Family inventory and usage audits.
- Type catalog handling.
- Batch family placement or replacement.
- Family parameter and type management.

## Does not belong here

- General geometry math (use `geometry`).
- Project-wide model cleanup (use `model-management`).
- Sheet and view automation (use `sheets-and-views`).

## Tool naming

Use a lowercase kebab-case folder id, for example `family-usage-audit`. See the
catalog in the root README for current tools and
[docs/ADDING-A-SCRIPT.md](../../docs/ADDING-A-SCRIPT.md) for the package
standard.
