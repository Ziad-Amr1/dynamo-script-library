# Sheets & Views

Tools that create, organize, number, rename, or export Revit sheets and views.

## Belongs here

- Batch sheet creation and duplication.
- Sheet numbering and renaming.
- View placement, alignment, and viewport management.
- Sheet and view exports (PDF, DWG, image).
- View template and crop-region workflows.

## Does not belong here

- Parameter transfer unrelated to sheets (use `parameters`).
- Schedule content and documentation reports (use `documentation`).
- General string helpers (use `utilities`).

## Tool naming

Use a lowercase kebab-case folder id, for example `batch-sheet-creator`. See the
catalog in the root README for current tools and
[docs/ADDING-A-SCRIPT.md](../../docs/ADDING-A-SCRIPT.md) for the package
standard.
