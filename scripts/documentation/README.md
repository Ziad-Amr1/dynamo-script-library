# Documentation

Tools that produce annotations, numbering, schedules, exports, reports, and other
project documentation.

## Belongs here

- View annotation and numbering workflows, including text notes and tags.
- Schedule creation and export.
- PDF, Excel, CSV, and image report generation.
- Drawing register and issue-sheet workflows.
- Documentation QA checks.
- Data extraction for project handover.

## Does not belong here

- Sheet creation and view placement (use `sheets-and-views`).
- Parameter write-back workflows (use `parameters`).
- Generic string cleanup (use `utilities`).

## Tool naming

Use a lowercase kebab-case folder id, for example `drawing-register-export`. See
the catalog in the root README for current tools and
[docs/ADDING-A-SCRIPT.md](../../docs/ADDING-A-SCRIPT.md) for the package
standard.
