# Dynamo Script Library v0.1.0

Released 2026-10-29.

This is the first public development snapshot of the library. It packages three
Dynamo/Revit tools for direct download, together with installation instructions,
manifests, changelogs, and checksums. The tools are usable for testing, but
none has been verified in a live Revit session yet.

## Highlights

- Three ready-to-extract tool packages: Text Find & Replace, Car Ramp Generator,
  and Parking Numbering.
- No Git, command line, or GitHub account is required to download or install a
  tool.
- Every ZIP includes its `.dyn` and/or Python entry point, a user-facing README,
  a changelog, a manifest, and a package manifest.
- All tools use CPython 3 and have no Dynamo package dependencies.

## Changes

### Added

- Initial repository tooling for catalog generation, manifest validation,
  deterministic ZIP packaging, and release publishing.
- Text Find & Replace, a pure-Python CPython 3 helper with no Revit API
  dependency.
- Car Ramp Generator, a cleaned Revit 2025 Dynamo graph with the `get_Name()`
  fix, embedded Python, an English README, an Arabic README, and a screenshot.
- Parking Numbering, a cleaned active-view numbering graph with one visible
  start-number input.
- Beginner-oriented documentation for downloading, authoring, versioning,
  releasing, and troubleshooting tools.

### Changed

- The maintained Car Ramp graph uses the fixed name helper. The earlier graph
  is kept only under `legacy/` for reference and is excluded from the ZIP.
- The maintained Parking graph removes the unused Boolean input and exposes the
  start number as `IN[0]`. The original graph is kept only under `legacy/` and
  is excluded from the ZIP.

### Fixed

- Car Ramp Generator replaces direct `.Name` access that could raise
  `Property cannot be read` in Dynamo with Revit 2025.
- Parking Numbering removes an unused input so the graph exposes only the value
  the script actually uses.

### Deprecated

- None.

### Removed

- None from the repository. Superseded source files were moved into each tool's
  `legacy/` folder rather than deleted.

## Breaking changes

None. This is the first repository release.

## Compatibility

**No Revit or Dynamo version is verified for this release.** The compatibility
arrays in every `script.json` are intentionally empty because no tool has been
run against a live Revit model.

| Tool | Target or requirement | Live Revit verification |
| --- | --- | --- |
| Text Find & Replace | Any Dynamo version using the CPython 3 engine; Python 3.8 or newer. No Revit API dependency. | Not verified |
| Car Ramp Generator | Revit 2025, Dynamo `3.0.3.7597` graph format, CPython 3. | Not verified |
| Parking Numbering | Revit 2025, Dynamo `3.0.3.7597` graph format, CPython 3. | Not verified |

- Python engine: **CPython 3 only**. IronPython 2.7 is not supported.
- Dynamo packages: none.
- Third-party Python packages: none.
- The two Revit graphs are targeted at Revit 2025 and may not open or run
  correctly in other Revit or Dynamo versions.
- Test every tool on a copy of the model before using it in production.

## Installation

1. Download the ZIP for the tool you need from the release page.
2. Extract the ZIP to a permanent folder, for example
   `C:\DynamoTools\parking-numbering`. Do not run a tool from inside the ZIP
   archive.
3. Open the extracted `README.md` and follow its installation and usage steps.
4. For the Dynamo graphs, open Revit, select **Manage > Dynamo**, and open the
   `.dyn` file with **File > Open**.
5. Confirm the Python node is set to **CPython 3**, review the inputs, and run
   the graph on a copy of the model.
6. For Text Find & Replace, follow the README to paste or import `script.py`
   into a CPython 3 Python node.

You do not need Git, a terminal, or an Autodesk account to install these
packages. No Dynamo packages are required.

## Known limitations

### Car Ramp Generator

- Not tested in a live Revit session; the graph and embedded Python were
  validated structurally.
- Targets Revit 2025 only and may fail in other Revit versions.
- Curb strips are floors, not walls or railings. Check the selected floor type
  and the resulting section.
- The original design draft appears to show a 500 mm center divider, while the
  script default is 300 mm. Confirm the required width.
- Overhead clearance is reported only; it is not checked against beams, ducts,
  or other geometry.
- High slopes above 10% use two 3000 mm transitions and can fail when the level
  difference is too small.
- Railings, drainage, signage, floor finishes, and existing elements are not
  handled.

### Parking Numbering

- Not tested in a live Revit session; the graph and embedded Python were
  validated structurally.
- Targets Revit 2025 only and may fail in other Revit versions.
- Creates independent text notes, not parking parameters or Revit tags.
- Running it twice creates duplicate notes. Undo or delete the previous notes
  before rerunning.
- Ordering uses model X/Y axes, not the rotation of the active view.
- Partial success is possible: notes created before an error remain in the
  model, and the error is returned in the output.
- The active view must support text notes, and only the `OST_Parking` category
  is processed.
- Row tolerance and text size are constants in `script.py`, not graph inputs.

### Text Find & Replace

- Not verified in Dynamo or Revit.
- A pure-Python helper: it does not read or write a Revit model by itself.
- Processes strings only. Convert numbers, IDs, and other types first.
- Regular expressions use Python `re` syntax, not .NET or Revit syntax.
- Case-insensitive matching follows Python Unicode behavior at edge cases.
