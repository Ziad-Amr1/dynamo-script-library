# Dynamo Script Library v0.1.1

Released 2026-10-29.

This release updates **Parking Numbering** to version `0.1.1`, introducing
improved geometric center calculation for rotated parking bays, non-destructive
duplicate avoidance when re-running the script, and refined annotation detection
logic that prevents skipping parking spaces due to unrelated text annotations.
The tools remain in development status and require manual testing in a live Revit
session before production use.

## Highlights

- **Parking Numbering v0.1.1:**
  - **Sequential numbering without gap consumption:** When existing spaces are
    skipped, the sequence counter does not advance; newly numbered spaces
    strictly start from the configured starting number (e.g. `01`).
  - **Safe renumbering mode:** Added an explicit toggle (`IN[1]` Renumber existing
    labels). When `True`, existing numbering labels are updated in-place without
    creating duplicate notes. When `False` (safe mode), stalls with existing
    labels are preserved.
  - **Angled bay label association:** Associates existing numbering notes via
    proximity to each stall center (3.5 ft radius), eliminating false-positive
    overlaps caused by axis-aligned bounding boxes on adjacent angled stalls.
  - **Geometric center placement:** Uses transformed view bounding-box corners
    with fallbacks to model-level bounding boxes and location points. Correctly
    places number notes at the center of rotated and oriented parking spaces.
  - **Protection of unrelated text:** Unrelated descriptive annotations (e.g.
    `RESERVED`, `EV ONLY`, `DO NOT BLOCK`, `ACCESSIBLE`) are ignored and never
    overwritten or deleted.
  - **Synchronized Python entry point:** Ensures `script.py` and the embedded
    Python node in `ParkingNumbering.dyn` are identical.
- **Automated verification:** Added unit tests verifying geometric centering
  across standard parking dimensions (2.3 × 5.0 m, 2.4 × 5.0 m, and 2.5 × 5.0 m)
  at various rotation angles (0° to 180°), sequential numbering with skipped spaces,
  renumbering mode, and annotation pattern discrimination.

## Changes

### Parking Numbering (v0.1.0 → v0.1.1)

- **Fixed:** Sequential numbering no longer consumes numbers for skipped spaces;
  new numbers start strictly from the configured starting number (e.g. `01`).
- **Fixed:** Angled parking bays associate labels via proximity (3.5 ft radius),
  preventing false-positive conflicts caused by axis-aligned bounding boxes
  overlapping adjacent stalls.
- **Fixed:** Number placement uses transformed bounding-box corners, accurately
  centering notes on rotated or oriented parking bays.
- **Added:** Explicit renumbering mode (`IN[1]`) allowing in-place updates of
  existing labels starting from `01` without creating duplicate notes.
- **Fixed:** Existing annotation detection filters for numeric/numbering labels,
  avoiding false-positive conflicts from unrelated text (such as "RESERVED").
- **Changed:** Summary dictionary output now includes `TextNotesCreated`,
  `TextNotesUpdated`, `TotalNumbered`, `SkippedExistingText`, `ExistingTextConflicts`,
  `StartNumber`, and `RenumberExisting`. The output tuple returns
  `(numbered_notes, errors, no_location, summary)`.
- **Documentation:** README and CHANGELOG updated with placement details,
  renumbering usage, and manual testing instructions.

### Repository & Tooling

- **Tests:** Added unit tests covering geometric center calculations for
  dimensions 2.3 × 5.0 m, 2.4 × 5.0 m, and 2.5 × 5.0 m across rotations (0°–180°),
  bounds overlap checks, and text detection patterns.
- **Catalog:** Updated root `README.md` catalog to reflect Parking Numbering v0.1.1.

## Installation

1. Download the tool ZIP (`parking-numbering-v0.1.1.zip`).
2. Extract the archive to a permanent folder (e.g. `C:\DynamoTools\parking-numbering`).
   Do not run graphs directly from within a ZIP.
3. In Revit 2025, open **Manage > Dynamo**.
4. Open `ParkingNumbering.dyn` via **File > Open**.
5. Set the **Start number** node (`IN[0]`, default `1`).
6. Run the graph manually on a copy of your model.

## Known limitations

- **Not tested in a live Revit session.** All geometric and packaging checks
  were conducted statically and via unit tests; verify in Revit before production use.
- **Text notes are view-specific annotations,** not element parameters or tags.
- **Row sorting uses model X/Y axes;** rotated views may produce a visual order
  that differs from the model coordinates.
- **Text size is fixed at 150 mm** in `script.py` (`TEXT_SIZE_MM`), unless
  modified in the script.
